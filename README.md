# UTS Pemrograman Web 2

Project Laravel Personal Web Profile

## Fitur
- Menampilkan data Education
- Menampilkan data Skills

## Cara Menjalankan
1. Clone repository
2. Jalankan:
   php artisan migrate
   php artisan db:seed
   php artisan serve

3. Buka di browser:
   http://localhost:8000/education
   http://localhost:8000/skills
