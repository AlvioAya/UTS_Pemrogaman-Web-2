# UTS Pemrograman Web 2

Project Laravel Personal Web Profile

## Fitur
- Menampilkan data Education
- Menampilkan data Skills

## Cara Menjalankan
1. Clone repository
2. Jalankan:
3. php artisan migrate
4. php artisan db:seed
5. php artisan serve

6. Buka di browser:
7. http://localhost:8000/education
8. http://localhost:8000/skills
